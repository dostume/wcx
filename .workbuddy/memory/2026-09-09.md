
## RoundAvatars 编译错误修复（17:30-17:45）

### 问题
RoundAvatars.kt 在 commit 23b3db3 引入后无法编译，存在多个错误：
1. `dexConstructor(allowFailure = true)` — `dexConstructor` 无 `allowFailure` 参数，只有 `throwOnFailure`
2. `methodAvatarModify by dexMethod(allowFailure = true)` — 缺少空 lambda `{ }`，导致 Kotlin 编译器选择无参版本
3. `companion object` 在 standalone `object` 内不合法
4. `DexConstructorDelegate` 缺少 `isPlaceholder` 属性

### 修复
1. `DexDelegates.kt`: 为 `DexConstructorDelegate` 添加 `isPlaceholder` 属性
2. `RoundAvatars.kt`:
   - `ctorAvatarCreate` 改用 `throwOnFailure = false`
   - `methodAvatarModify` 添加空 lambda `{ }`
   - 移除 `companion object`，将 `TAG` 常量直接定义在 object 内部
   - 添加缺失的 `import com.Johnny.wcx.utils.WeLogger`
